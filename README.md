# Auto Escola Pola 🚗💨
> **Centro Asociado AVAE en L'Eliana (Valencia) · Formando conductores responsables desde 1984.**

Landing page de alta conversão, responsiva e otimizada para a **Auto Escola Pola**, referência em formação de condutores (Permissão B, motos e cursos profissionais) na região de L'Eliana e Valência, Espanha.

---

## 🌟 Destaques do Projeto

- **Design System Minimalista & Sofisticado**: Inspirado na identidade oficial AVAE / Pola com padrão esmeralda profundo e relevo 3D.
- **100% Responsivo & Mobile-First**: Perfeita visualização em smartphones, tablets e desktops.
- **Carrossel Editorial de Resenhas do Google**: Depoimentos reais de alunos aprovados em alta legibilidade e contraste WCAG AAA.
- **Alta Conversão (Direct-to-WhatsApp)**: CTAs estratégicos e botão flutuante inteligente configurados com mensagens pré-formatadas para matrícula imediata.
- **Arquitetura Web Segura & Semântica**: Carregamento assíncrono, imagens otimizadas para produção e headers de segurança.

## 🚀 Como Executar Localmente

Como o projeto é construído em HTML5 puro, CSS moderno e JavaScript vanilla otimizado, não requer instalação de dependências ou build complexo:

1. Clone o repositório:
   ```bash
   git clone https://github.com/ahk2001/pola.git
   ```
2. Abra o arquivo `index.html` diretamente em seu navegador web (Chrome, Edge, Firefox, Safari).
